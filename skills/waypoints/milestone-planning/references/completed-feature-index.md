# Completed Feature Index

Use only when no stronger repository convention exists. Keep the list ungrouped and newest-first.

```md
# Completed Features

```

Add an entry only after the Feature owner confirms Acceptance and integration proof. Keep the Feature directory in place as the detailed record. Do not copy owner, Tasks, MR, verification evidence, or Milestone detail into this index.
